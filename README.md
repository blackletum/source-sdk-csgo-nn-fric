# Source SDK CSGO

## Usage
Download 27/6/2017 version of csgo (last version with symbols valve failed to strip because of OSX 64bit update) in steam console.
Build and replace the origin dlls (dlls compiled will output to source-sdk-csgo/game/bin).
### General Game File
``
download_depot 730 731 1280406795627336919
``
### Windows
``
download_depot 730 732 4200891197920863090
``
### Linux
``
download_depot 730 734 1171730254624985529
``
### OSX
``
download_depot 730 733 809975343053287928
``

## Aim
Fully reverse CSGO with modern features also replace some old 3rdparty libraries.
